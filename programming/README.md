## 🧠 Key Concepts

### Program
A program is a set of instructions written to tell a computer how to perform a particular task.

### Programming Language
A programming language is a formal language used to write instructions for a computer.

Examples include Python, R, C and Java.

### High-Level Language
A high-level programming language is designed to be easier for humans to read and write while abstracting many low-level details of computer hardware.

### Machine Language
Machine language consists of instructions in a form that can be directly executed by a computer's processor.

### Compilation
Compilation involves translating source code into another executable or lower-level representation before or as part of execution.

### Interpretation
Interpretation involves executing a program through an interpreter rather than relying on the traditional process of producing a standalone executable first.

### Debugging
Debugging is the process of identifying, locating and correcting errors in a program.

## 🐛 Types of Programming Errors

### Syntax Error
Occurs when the code violates the syntax or grammatical rules of the programming language.

### Runtime Error
Occurs while a program is executing.

### Logic Error
Occurs when a program runs but produces an incorrect result because the underlying logic is wrong.

## 🧬 Relevance to Bioinformatics

Programming is an essential skill in bioinformatics because biological research generates large and complex datasets.

Programming allows bioinformaticians to:

- Automate repetitive tasks
- Process large biological datasets
- Analyse DNA, RNA and protein sequences
- Perform statistical analyses
- Visualize biological data
- Develop reproducible computational workflows
